AnalysisLineIcon renders a small solid or dashed line marker in a given colour. Use it as a legend swatch so users can match a label to its line on a chart.

## When to use

- In chart legends, selectors, or tooltips to identify a series by colour and line style.
- To distinguish historical series (solid) from forecast series (dashed).

## When not to use

- As a generic decorative icon; it only conveys meaning next to a chart.
- To indicate status or severity; use Chip instead.
