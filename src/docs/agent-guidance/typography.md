The system pairs KMR Apparat for display and headings with Manrope for body copy. Sizes come from the --text-_ scale, display sizes from --text-display-_, and rhythm from the --lh-_ and --tracking-_ tokens. Set sizes through tokens rather than raw pixel values.

## When to use

- The --text-\* scale for UI text, labels, and headings.
- The --text-display-\* sizes for hero and editorial moments only.

## When not to use

- Display sizes inside dense product UI; the largest heading there should be --text-3xl.
