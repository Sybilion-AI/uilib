The --p-\* tokens are the canonical spacing scale: each step is a multiple of 4px, from --p-1 (4px) up to --p-24 (96px). Use them for padding, gaps, and margins instead of raw pixel values, so layouts share the same rhythm everywhere.

## When to use

- Gaps and padding inside components and page sections.
- Vertical rhythm between sections, cards, and form fields.

## When not to use

- One-off pixel values that sit between steps; pick the nearest token instead.
